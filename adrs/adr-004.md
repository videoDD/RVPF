# ADR-004: Time-Based Execution via Unreal Sequencer

## Status
Accepted

## Context
A major challenge in Virtual Production is ensuring that a live performance and a recorded playback behave identically. If live inputs (e.g., DMX, MIDI) are handled differently than recorded animation data, the system requires duplicated logic and becomes highly error-prone.

## Decision
The RVPF will align its execution model with the time-based timeline of the Unreal Sequencer (and Take Recorder). All external inputs are converted into the unified impulse model and anchored to the Sequencer's timeline. The `StudioObject` reacts to these impulses without needing to know if the source is live hardware input or a recorded Sequencer playback track.

## Consequences
* **Positive:** The exact same scene can be controlled live, recorded, played back, or simulated using a single, unified logic path.
* **Positive:** Seamless integration with Unreal Engine's native cinematic tools.
* **Negative:** Requires careful synchronization and temporal management between live hardware inputs and the Engine's internal Sequencer time.
