# ADR-002: Semantic Neutrality of Incoming Impulses

## Status
Accepted

## Context
Virtual Production environments receive a continuous stream of data from diverse sources (faders, trackers, sensors). Treating these raw data points inherently as meaningful actions leads to messy, protocol-specific business logic. For example, a spatial coordinate from a Vive tracker `(2.31, 1.74, 0.85)` is just a float vector; it has no innate semantic value on its own.

## Decision
The RVPF will initially process all incoming information exclusively as raw **Impulses**. An impulse carries no business or semantic meaning; it is merely a standardized temporal data point. Semantic meaning is only applied later in the pipeline when the impulse is evaluated against the current production context.

## Consequences
* **Positive:** Complete decoupling of sensor data acquisition from business logic.
* **Positive:** Provides a unified, protocol-agnostic entry point for all data sources (a MIDI fader and a tracking coordinate enter the system through the same impulse mechanism).
* **Positive:** Establishes a clear boundary between technical measurements and production meaning.
